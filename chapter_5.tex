\chapter{Design and Implementation}\label{chap:chapter5}

\section{Knowledge Base Design}

The knowledge base will serve as the foundation of the chatbot system, enabling accurate scenario generation, user profiling, and feedback delivery. It will consist of several interconnected components:

\begin{itemize}
    \item \textbf{Scenario Database} – It will store predefined conversational scenarios aligned with Grice’s Maxims and pragmatic principles.
    \item \textbf{User Database} – It will maintain user profiles, including past conversations, performance data, and current proficiency levels.
    \item \textbf{Feedback System} – It will generate personalized feedback based on user responses, mapped to specific pragmatic competencies such as relevance, clarity, and informativeness.
\end{itemize}


\section{Software Design and Implementation}

The chatbot system will be built on top of a large language model (Gemini), implemented using Python, and will follow a conversational AI pipeline:
\begin{itemize}
    \item \textbf{Load and format dataset} – Prepare dialogue data for use.
    \item \textbf{Load \hl{Gemini} model} – Access the model for inference or fine-tuning.
    \item \textbf{Train with data collator} – Perform fine-tuning on task-specific data.
    \item \textbf{Interact via conversation engine} – Engage in real-time dialogue with the user.
\end{itemize}
First, dialogue data, from the GRICE dataset, will be prepared and formatted to reflect various social communication scenarios. The
system uses predefined dialogue data drawn from the GRICE dataset. Real-time
conversation is handled via the Gemini API, which responds to user input using contextual understanding based on Gricean maxims
and the scenario’s goals. Subsequently, Gemini is loaded through an API to handle inference, while a data collator 
will be used to manage input lengths. Finally, the model engages in real-time econversations with users, providing contextually apropriate responses to support 
social communication training.

\section{Algorithms}

The system will rely on the following core algorithms to analyze input, assess pragmatic adherence, and generate appropriate responses:

\subsection{Intent Recognition}

The \textbf{Intent Recognition} algorithm is responsible for determining the user's intent based on their input. This ensures that the chatbot maintains contextual relevance and keeps the conversation focused on the right topic. By using an external API like Gemini, the system can classify user inputs into different intent categories, allowing for a more targeted and accurate response. The function works by sending the user's input to the Gemini API, which classifies the intent, and then returns the detected intent to guide the chatbot’s response.

\begin{lstlisting}[caption={Intent Recognition Algorithm}, label={lst:detectintent}]
FUNCTION detect_intent(user_input):
    INITIALIZE GeminiAPI with API_KEY
    CALL classify_intent on user_input using GeminiAPI
    RETURN detected intent from response
END FUNCTION
\end{lstlisting}


\subsection{Pragmatic Analysis}

The \textbf{Pragmatic Analysis} algorithm evaluates whether the user's response adheres to Grice’s Maxims, which are principles of communication that help maintain relevance, clarity, truthfulness, and informativeness. The algorithm checks for violations of these maxims by analyzing the user’s input. For example, it checks if the response is too short (Quantity Maxim violation), contains lies (Quality Maxim violation), is off-topic (Relation Maxim violation), or is unclear due to ambiguity (Manner Maxim violation). Based on the violations detected, the algorithm generates feedback to guide the user towards better communication practices.

\begin{lstlisting}[caption={Pragmatic Analysis}, label={lst:evaluatepragmatics}]
FUNCTION evaluate_pragmatic_adherence(user_input, expected_response):
    INITIALIZE feedback as an empty list

    CHECK if the input violates Quantity Maxim (e.g., too short)
        IF violation: APPEND feedback "Provide more detailed information"

    CHECK if the input violates Quality Maxim (e.g., lies)
        IF violation: APPEND feedback "Provide truthful responses"

    CHECK if the input violates Relation Maxim (e.g., off-topic)
        IF violation: APPEND feedback "Stay relevant to the conversation"

    CHECK if the input violates Manner Maxim (e.g., ambiguity)
        IF violation: APPEND feedback "Keep responses clear and unambiguous"

    RETURN feedback
END FUNCTION
\end{lstlisting}


\subsection{Feedback Generation}

The \textbf{Feedback Generation} algorithm constructs personalized feedback messages based on the pragmatic analysis. It informs the user about any violations of Grice's Maxims, offering suggestions to improve their communication. If no violations are found, the algorithm generates positive feedback, congratulating the user for providing a clear and relevant response. This ensures that users not only receive constructive criticism but also feel encouraged to continue improving their conversational skills.

\begin{lstlisting}[caption={LLM (Gemini API) Response Generation}, label={lst:generateresponse}]
FUNCTION generate_response(user_input, scenario):
    CREATE prompt with scenario and user_input
    CALL generate_text on GeminiAPI with prompt
    RETURN generated text from API response
END FUNCTION
\end{lstlisting}


\subsection{LLM (Gemini API) Integration for Response Generation}

The \textbf{LLM Integration} algorithm is responsible for generating responses that are contextually relevant and pragmatically sound.
This is achieved by integrating the Gemini API to generate text that aligns with the selected scenario and the user’s input.
The algorithm constructs a prompt that combines the scenario and the user’s input, and sends it to Gemini’s \texttt{generate\_text} method.
The generated text is then returned as the chatbot’s response. This ensures that the chatbot can handle various conversational
contexts and respond appropriately.

\begin{lstlisting}[caption={LLM (Gemini API) Response Generation}, label={lst:llmintegration}]
FUNCTION generate_response(user_input, scenario)
    CREATE prompt with scenario and user_input
    CALL generate_text on GeminiAPI with prompt
    RETURN generated text from API response
END FUNCTION
\end{lstlisting}


\section{GRICE Dataset Structure}

The GRICE dataset will be used to train the chatbot. Refer to Figure~\ref{fig:datasetstructure} for the structure of the dataset:

\begin{figure}[H]
    \centering
    \includegraphics[width=0.90\textwidth]{figures/dataset_structure.png}
    \caption{GRICE Dataset Structure}
    \label{fig:datasetstructure}
\end{figure}

The GRICE dataset is structured to include various scenarios based on the implicatures that come from Grice's Maxims. As such, each row of data in the dataset represents a unique social scenario in regard to a certain implicature.

\begin{itemize}
    \item \textbf{question:} \hl{This column contains the initial utterance or query from a speaker. It sets the immediate context and prompts the response that contains the pragmatic information to be analyzed.}
    \item \textbf{answer:} \hl{This column provides the direct response to the question. Crucially, this response often contains a conversational implicature, meaning it is pragmatically appropriate but may not be literally direct.}
    \item \textbf{explicit answer:} \hl{This column serves as the ``ground truth'' for the implicature. It provides the fully resolved, explicit meaning of what the speaker intended to convey in the ``answer'' column, making the implied meaning clear and unambiguous.}
    \item \textbf{options:} \hl{This column frames the task as a multiple-choice question. It contains a list of possible interpretations for the ``answer'', which includes the correct ``explicit answer'' along with several incorrect or misleading distractors.}
    \item \textbf{answer index:} \hl{This column provides the zero-based index of the correct answer within the ``options'' list. It is used to programmatically identify the correct choice, which is essential for both training the model and evaluating its performance on pragmatic reasoning tasks.}
    \item \textbf{dialog id:} \hl{This column is a dialogue identifier that groups related question--answer pairs into a single, coherent conversation. This allows the system to maintain contextual continuity across multiple conversational turns, ensuring that the interpretation of any single utterance can be informed by the preceding dialogue.}
\end{itemize}
