\chapter{Socius Chatbot}\label{sec:methodology}

\section{Software Overview}

This section provides an overview of Socius, a chatbot utilizing the APAM framework to enhance social communication skills, specifically pragmatics, to develop their ability to navigate social interactions effectively. The chatbot is designed to simulate real-world situations and conversations in which pragmatics becomes apparent and important. The social situations provided are pre-determined and modeled based on each of Grice's Maxims and Implicatures. It is also important to note that these situations were developed both by research and GPT 4.0, in which it was made critical to comply with Grice's theory. To do so, the chatbot would be modeled using the GRICE dataset (reference here). Moreover, this pragmatical assessment is based on Grice's Maxims, whicha re fundamental principles of pragmatics that guide effective communication. After the user has simualated conversation with the chatbot and the hypothetical social situation, the chatbot will then evaluate the users' pragmatical competence based on the user's responses and adherence to Grice's Maxims and implicatures. The chatbot will provide feedback and suggestions for improvement, allowing users to reflect on their conversation and thereby improve from the advice the chatbot provides. 

\section{Software Objectives}

% 

The objectives of the Socius chatbot are as follows:
\begin{itemize}
    \item To apply accurate siutation emulation based on situations in which pragmatics is present, utilizing the APAM Framework
    \item To integrate the GRICE dataset and map it to scenario-specific dialogue flows that correspond to each of Grice's Maxims.
    \item To develop a dialogue engine capable of detecting and analyzing user input for implicatures and maxim adherence.
    \item To store user interaction data securely for performance tracking and reflective feedback generation.
    \item To design a rule-based and/or ML-based scoring system that evaluates user responses against pragmatic criteria.
    \item To ensure extensibility for future addition of more pragmatic theories, languages, or user customization options.
\end{itemize}

\section{Software Design and Implementation}

The chatbot system will be built on top of a large lagnuage model (GPT-4), implemented using Python, and will follow a conversational AI pipeline:
\begin{itemize}
    \item \textbf{Load and format dataset} – Prepare dialogue data for use.
    \item \textbf{Load tokenizer and tokenize text} – Convert raw text into token IDs.
    \item \textbf{Load GPT-4 model} – Access the model for inference or fine-tuning.
    \item \textbf{Train with data collator} – Perform fine-tuning on task-specific data.
    \item \textbf{Interact via conversation engine} – Engage in real-time dialogue with the user.
\end{itemize}
First, dialogue data, from the GRICE dataset, will be prepared and formatted to reflect various social communication scenarios. The data will then be 
tokenized by using a tokenizer to convert text into machine-readable input. Subsequently, GPT-4 is loaded through an API to handle inference, while a data collator 
will be used to manage input lengths. Finally, the model engages in real-time econversations with users, providing contextually apropriate responses to support 
social communication training.

The conversation flow used in this chatbot-driven communication training system is structured into four sequential phases:
\textbf{Scenario Selection}, \textbf{Conversation Simulation}, \textbf{Evaluation}, and \textbf{Reflection or Retry}.
This flow was constructed with the goal of giving a clear, iterative loop for users to practice and improve their 
social communication skills in context-sensitive environments.

\begin{enumerate}
    \item \textbf{Scenario Selection} \\
    In this phase, the user selects a specific social scenario to engage with. These scenarios are designed to
    simulate real-world situations where effective communication is essential such as handling awkward moments,
    initiating small talk, or responding to indirect questions. This step allows the user to target specific
    conversational challenges aligned with their personal learning goals or areas of difficulty.

    \item \textbf{Conversation Simulation} \\
    Once a scenario is selected, the user engages in a simulated dialogue with an AI-driven chatbot. The
    conversation transpires naturally, with the user providing input and the chatbot responding in real time.
    This interactive phase emphasizes context, tone, and appropriate language use, mimicking real-life 
    communication. The simulation encourages the user to apply pragmatic strategies, such as reading between the 
    lines, interpreting implied meaning, and maintaining conversational relevance.

    \item \textbf{Evaluation} \\
    After the conversation ends, the system evaluates the user’s performance. This evaluation is grounded in 
    principles from linguistic pragmatics, particularly \textbf{Grice’s maxims} (Quantity, Quality, Relation, 
    and Manner). The chatbot assesses how well the user followed conversational norms, responded to social 
    cues, and maintained clarity and relevance. Feedback may include scores, highlight strengths, and point 
    out areas for improvement.

    \item \textbf{Reflection or Retry} \\
    The final stage prompts the user to either \textit{reflect} on the evaluation or \textit{retry} the 
    simulation to improve their response. Reflection helps the learner process feedback, internalize 
    conversational norms, and recognize specific pragmatic issues such as awkward phrasing or irrelevant 
    responses. If the user chooses to retry, they can immediately re-engage with the same scenario or select 
    a new one, reinforcing learning through repetition and iterative practice.
\end{enumerate}
